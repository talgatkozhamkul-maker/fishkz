# BACKLOG.md — идеи вне текущего скоупа

Источник: исследование рынка и аудит (июль 2026). Не делать без решения
владельца проекта; изменения скоупа — письменно, с пересчётом.

## Продукт (из конкурентного анализа)
- **Механика «цена проверена N дней назад»** с подтверждениями от владельцев
  прудов — killer-фича по исследованию: рыбаки гуглят именно цены платников.
  (Поле verified_at уже есть; нужна механика обновления.)
- **Быстрые отчёты с водоёма** («был вчера, клевал сазан») — перетягивает живое
  сообщество с форумов/Telegram. Метрика №1 продукта: доля карточек, обновлённых
  за 30 дней — устаревание убило всех предшественников.
- **Прогноз клёва** (коммодити — добавлять после локальной фактуры, не вместо).
- **Партнёрство с блогерами**: «место из видео → карточка водоёма».
- **Импорт объявлений** из Telegram/Instagram для холодного старта доски.
- Отзывы и рейтинги исполнителей; избранное; push-уведомления.
- Монетизация: продвижение объявлений, платное размещение баз/гидов.

## Карта (главная в стиле 2ГИС уже реализована на MapLibre + OpenFreeMap)
- Настоящие тайлы 2ГИС через их MapGL API — нужен ключ с dev.2gis.com
  (регистрация владельцем), у бесплатного тарифа есть лимиты.
- Кластеризация меток, когда водоёмов станет 200+.
- Фильтры прямо на карте (тип водоёма, платность, вид рыбы).
- «Водоёмы рядом со мной» списком по расстоянию от геопозиции.

## Технику (из аудита)
- Генерация типов из схемы: `supabase gen types typescript` вместо ручных типов.
- Supabase CLI для миграций вместо самописного скрипта (когда появится CI).
- CA-сертификат Supabase для строгого TLS в скриптах; ротация пароля БД при
  передаче проекта.
- Загрузка фото в объявлениях (bucket и политики уже готовы) + сжатие на клиенте.
- Фото водоёмов в карточках (schema поддерживает photos[]).
- Service worker с офлайн-заглушкой (manifest и иконки уже есть).
- Казахская локализация (вопрос №4 к заказчику).

## Организационное
- Переезд данных в РК (этап 2, ответственность владельца).
- Домен заказчика; свой SMTP (Resend) для OTP-писем, если письма Supabase
  попадают в спам.
