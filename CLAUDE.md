# CLAUDE.md — Рыболовный сервис Казахстана (рабочее название: FishKZ)

## О проекте
PWA-сервис для рыбаков Казахстана: каталог регионов и водоёмов, правила рыбалки,
доска объявлений услуг (путёвки, гиды, туры, попутчики). MVP для проверки спроса.
Полная спецификация — в SPEC.md. План работ — в PLAN.md.

## О владельце проекта
Владелец — руководитель ИТ-проектов, НЕ программист. Поэтому:
- Перед любой нетривиальной работой предлагай краткий план и жди подтверждения.
- Работай маленькими шагами: одна фича — одна задача.
- Объясняй технические решения простым языком, без жаргона.
- После каждой задачи давай шаги ручной проверки на телефоне.

## Стек (зафиксирован, не менять)
- Next.js (App Router) + TypeScript + Tailwind CSS
- Supabase: Postgres, Auth (вход по e-mail-коду / OTP), Storage (фото)
- Хостинг: Vercel. PWA: manifest + иконки + установка на экран.
- Новые библиотеки добавлять только после явного согласия владельца.

## Правила кода
- Server Components по умолчанию; client components — только где нужна интерактивность.
- ВАЖНО: каждая таблица в БД создаётся сразу с RLS-политиками. Таблиц без RLS быть не должно.
- Секреты только в .env.local. В клиентский код попадают только
  NEXT_PUBLIC_SUPABASE_URL и anon key. Ключ service_role в коде НЕ использовать.
- Валидация всех форм через zod (клиент + сервер).
- UI-тексты на русском, идентификаторы в коде на английском.
- Перед применением миграции БД — показать SQL владельцу и объяснить, что он делает.
